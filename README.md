# Smart App – React Native

Native version of Smart App created in React Native using Expo.

## Technologies

- React Native (Expo)
- TypeScript
- React Navigation
- React Query
- API – backend

## To run your project, navigate to the directory and run following npm commands.

- cd smart-app-rn
- npm install
- npm start (launch app via Expo)
## for emulators below
- npm run android
- npm run ios # you need to use macOS to build the iOS project - use the Expo app if you need to do iOS development without a Mac
- npm run web
